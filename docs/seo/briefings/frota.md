## Observação sobre esta página

`/frota` capta pouca busca, mas é onde a decisão se fecha. Todas as páginas de
destino vão linkar para cá.

**Foto de banco de imagem destrói a credibilidade desta página inteira.** Hoje
o site usa imagens do Unsplash nas seções de serviço — aqui isso não funciona,
porque o cliente está avaliando exatamente o veículo em que vai entrar.
