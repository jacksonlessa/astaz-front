# Briefing — Transporte Corporativo

**URL**: `/servicos/transporte-corporativo`
**Intenção de busca**: "transporte corporativo balneário camboriú", "transporte
executivo para empresas", "carro executivo para reuniões"
**Status**: ⬜ vazio
**Prioridade**: 🟡 média em volume, **alta em valor** — é a página do cliente
recorrente, não da corrida avulsa

---

## O papel desta página (leia antes de preencher)

Duas fronteiras precisam ficar nítidas, ou esta página canibaliza vizinhas:

| Esta página fica com | Vai para outra página |
| --- | --- |
| Agenda executiva do dia a dia: reuniões, visitas técnicas, deslocamentos entre compromissos | Congressos, feiras e shows → `/servicos/transporte-eventos` |
| **Veículo à disposição por período**, com roteiro que muda durante o dia | Passeio turístico com paradas → `/servicos/city-tour` |
| Traslado de executivo/convidado que a empresa está recebendo | O termo genérico "transporte executivo" → home |

O ângulo "motorista à disposição" **mora aqui**. A página
`/servicos/motorista-particular` foi descartada porque aquele termo atrai quem
procura vaga de emprego — mas a intenção comercial real (um veículo e um
motorista dedicados por um período) é desta página.

## 1. Quem chega nesta página

Quase nunca é o passageiro. É quem **organiza** o transporte de outra pessoa:
secretária executiva, assistente, RH, gerente de eventos, ou o dono da empresa
resolvendo o deslocamento de um cliente que vem visitar.

Essa diferença muda tudo na copy: **quem contrata está com a reputação em
jogo.** Se o carro atrasa, quem se queima é ela, não o motorista.

## 4. Questões administrativas (decisivas para PJ)

Esta seção não existe nas páginas de destino, mas **é o que trava ou destrava
uma venda corporativa.** Empresa não contrata o que não consegue lançar na
contabilidade.

| Pergunta | Resposta |
| --- | --- |
| Emite nota fiscal? | |
| Atende com contrato/faturamento mensal, ou é pagamento por viagem? | |
| Formas de pagamento aceitas por PJ (boleto, PIX, transferência, cartão) | |
| Emite relatório ou comprovante de deslocamentos para prestação de contas? | |
| Aceita contrato de confidencialidade (NDA) se o cliente pedir? | |
| Tem CNPJ ativo e seguro para passageiros? | |

> Se pelo menos "emite nota fiscal" e "faturamento mensal" forem sim, isso vira
> um bloco de destaque na página — é diferencial concreto contra app de
> corrida, que não resolve isso bem.

## 9. O que NÃO dizer

- Não prometer disponibilidade imediata sem agendamento
- Não prometer sempre o mesmo motorista, a menos que a operação sustente isso
- Não afirmar exclusividade ou frota maior do que a real
- Não citar nome de cliente corporativo sem autorização por escrito — em
  transporte executivo, discrição é o produto
